# ★ SUPERSTAR 심사 시스템 ★

웹 기반으로 동작하는 오디션 및 대회 심사 평가 시스템입니다. 화려한 네온 스타일의 UI와 함께 모바일에 최적화되어 있습니다.

## 주요 기능
- **심사위원 개별 로그인**: 1번부터 9번까지의 심사위원 번호를 선택하여 개별적으로 평가를 진행합니다.
- **팀명 커스텀 등록**: 관리자 인증코드(`1125`)를 통해 30개 참가팀의 이름을 자유롭게 변경할 수 있습니다.
- **실시간 평가 저장**: 평가 점수(1~10점)와 심사평은 기기의 LocalStorage에 안전하게 자동 저장됩니다.
- **자동 순위 집계**: 관리자 메뉴를 통해 최고점과 최저점을 제외한 7명의 점수를 자동 합산하여 최종 순위를 산출합니다. (제외된 점수는 붉은색 취소선으로 표시)

## 사용 기술
- HTML5
- CSS3 (네온 그라데이션, 다크 테마 적용)
- Vanilla JavaScript (Local Storage 활용)

## 보안 접근 코드
- **참가팀 등록**: `1125`
- **전체 심사결과 확인**: `1125`
